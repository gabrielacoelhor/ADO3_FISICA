# ADO 3 — Opção B

- `ADO3_Colisao_Inelastica.py`: implementação exigida em Python com Matplotlib.
- `index.html`: versão web complementar para GitHub Pages.

Instalação: `pip install -r requirements.txt`
Execução: `python ADO3_Colisao_Inelastica.py`

A simulação usa MRU por trechos: cada bloco tem sua velocidade inicial até o instante calculado do contato; após o choque perfeitamente inelástico, ambos mantêm a separação de contato e se deslocam com a velocidade comum V.
