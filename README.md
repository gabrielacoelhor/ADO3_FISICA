# ADO-3 — Colisão perfeitamente inelástica (Opção B)

Projeto em Python para a atividade ADO-3 de Física: Práticas Extensivas.

## Arquivos
- `ADO3_Colisao_Inelastica.py`: animação interativa e cálculos físicos.
- `Relatorio_ADO3_Opção_B.pdf`: relatório com as respostas Q1–Q5.
- `requirements.txt`: bibliotecas necessárias.

## Como executar
1. Instale Python 3.
2. Abra o terminal na pasta do projeto.
3. Instale as dependências:

```bash
pip install -r requirements.txt
```

4. Execute:

```bash
python ADO3_Colisao_Inelastica.py
```

## Controles
- Sliders para massas `m1`, `m2`, velocidades `v1`, `v2` e duração do contato.
- Botão **Pausar/Continuar**.
- Botão **Reiniciar**.
- A animação indica o instante do choque e mostra os blocos unidos após a colisão.
- Os painéis exibem momento, energia cinética, impulsos e força média.

## Valores iniciais
`m1 = 2 kg`, `m2 = 3 kg`, `v1 = 5 m/s`, `v2 = 0 m/s`, `Δt = 10 ms`.
